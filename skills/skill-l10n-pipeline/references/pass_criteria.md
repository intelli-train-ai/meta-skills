# 通过标准定义

## 概述

翻译后的 skill 必须满足以下全部三条标准才算通过评测。

## 标准 1: 断言通过率

**公式**: CN_pass_rate >= EN_pass_rate × 0.95

- CN_pass_rate: 中文版在所有 eval 上的平均断言通过率
- EN_pass_rate: 原版在所有 eval 上的平均断言通过率
- 0.95: 容差系数（允许 5% 的差异）

**为什么是 0.95**: 翻译可能导致极少数边界情况的行为差异（如日期格式、纸张尺寸选择），5% 的容差避免对翻译质量的过度惩罚。

**示例**:
- EN 通过率 1.0, CN 通过率 0.96 → 0.96 >= 0.95 → 通过
- EN 通过率 0.8, CN 通过率 0.7 → 0.7 >= 0.76 → 不通过

## 标准 2: 盲评均分

**公式**: CN_avg_score >= EN_avg_score - 1.0

- CN_avg_score: 中文版在所有 eval 上的盲评均分（1-10）
- EN_avg_score: 原版的盲评均分
- 1.0: 容差分值

**为什么是 1.0**: 盲评是主观评分，允许 1 分的波动。如果差距超过 1 分，说明翻译版在质量上有明显不足。

**示例**:
- EN 均分 8.5, CN 均分 8.0 → 8.0 >= 7.5 → 通过
- EN 均分 9.0, CN 均分 7.5 → 7.5 >= 8.0 → 不通过

## 标准 3: 无 critical 错误

**定义**: analysis.json 的 loser_weaknesses 中不能有 severity="critical" 的条目。

**什么算 critical**:
- 生成内容中出现错别字、乱码（如"栉赎"代替"栽培"）
- 生成内容中出现严重的语法错误或成语误用
- 输出文件损坏或无法打开
- 安全相关问题

**什么不算 critical**:
- 纸张尺寸选择差异（US Letter vs A4）
- 页脚格式差异（Page X vs 纯数字）
- 排版细节差异（首行缩进有无）
- 这些属于 medium 或 low severity

## 边界情况

- 如果所有 eval 都平局（CN = EN），视为通过
- 如果 analysis.json 不存在，跳过标准 3
- 如果只有 1 个 eval，仍然应用所有标准
